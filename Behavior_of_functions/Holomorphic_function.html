\(\newcommand{\cn}{\mathbb{C}^n}\) \(\newcommand{\t}{\triangle}\)

Definition 1

The holomorphic function \(f\) is said to be regular of order \(k\) in \(z_n\) at the point \(w\) if \(f(w_1,\cdots,w_{n-1},z_n)\), considered as a holomorphic function of the single variable \(z_n\), has a zero of order \(k\) at the point \(z_n=w_n\). Equivalently, the condition can be stated as follows: \[ f(w)=0,\frac{\partial f}{\partial z_n}(w)=0,\ldots,\frac{\partial^{k-1} f}{\partial z_n^{k-1}}(w)=0,\frac{\partial^{k} f}{\partial z_n^{k}}(w)\neq 0\,. \]

Theorem 1: Implicit Function Theorem

If \(f(z_1,\cdots,z_n)\) is holomorphic in an open polydisc \(\t{(w;r)}\subset \cn\) and is regular of order \(1\) in \(z_n\) at the point \(w\), then in an open polydisc \(\t(w;\delta)\subset \t(w;r)\) there exists a unique holomorphic function \(\varphi(z_1,\cdots,z_{n-1})\) such that:

  1. \(\varphi(w_1,\cdots,w_{n-1})=w_n\);

  2. \(\vert \varphi(z_1,\cdots,z_{n-1}) -w_n \vert < \delta_n\) in \(\t(w;\delta_1,\dots,\delta_{n-1})\);

  3. \(f(z_1,\cdots,z_{n-1},z_n)=0\) at a point \(z\in \t(w;\delta)\) if and only if \(z_n=\varphi(z_1,\cdots,z_{n-1})\).

To prove this we need a lemma.

Lemma 2

If \(f\) is a function which is holomorphic in an open polydisc \(\t(w;r)\) and which is regular of order \(k\) in \(z_n\), then there is an open polydisc \(\t(w;\delta)\subset \t(w;r)\) such that for every point \((a_1,\dots,a_{n-1})\in \t(w;\delta_1,\dots,\delta_{n-1})\) the function \(f(a_1,\cdots,a_{n-1},z_n)\), as a function of the single complex variable \(z_n\), has precisely \(k\) zeroes (counting multipicities) in the disc \(\vert z_n -w_n \vert < \delta_n\).

Proof. To simplify notation we may assume that the point \(w\) is the origin in \(\cn\). By hypothesis \(f(0,\cdots,0,z_n)\) has a zero of order \(k\) at the point \(z_n=0\). Since the zeroes of a holomorphic function of one variable are isolated, there is a constant \(0<\delta_n<r_n\) such that \(f(0,\cdots,0,z_n)\neq 0\) for \(0 < \vert z_n \vert \leq \delta_n\); set \[ \inf_{\{\vert z_n \vert = \delta_n \}} \vert f(0,\cdots,0,z_n) \vert = \epsilon > 0\,. \tag{1}\] Since \(f(z)\) is continuous in an open neighborhood of the compact set \(z_1=0,\dots,z_{n-1}=0,|z_n|=\delta_{n}\), there are constants \(\delta_{j}\) with \(0 < \delta_j < r_j\), (\(j=1,\dots,n-1\)), such that \[ \vert f(z_1,\cdots,z_n) -f(0,\cdots,0,z_n) \vert < \epsilon \tag{2}\] for \(\vert z_j \vert < \delta_j\) where \(j=1,\dots,n-1\) and \(|z_n|=\delta_n\).

Now for any point \((a_1,\dots,a_{n-1})\) with \(\vert a_j \vert < \delta_j\) consider \(f(a_1,\cdots,a_{n-1},z_n)\) as a function of \(z_n\) alone. By Rouché’s Theorem, it follows from Equation 1 and Equation 2 that \(f(a_1,\cdots,a_{n-1},z_n)\) has the same number of zeroes in \(|z_n| < \delta_n\) as has \(f(0,\cdots,0,z_n)\), which by hypothesis is \(k\).

Proof. Select an open polydisc \(\t(w;\delta)\subset \t(w;r)\) for which the conclusion of Lemma 2 holds. Then for any point \[ (z_1,\cdots,z_{n-1}) \in \t(w;\delta_1,\cdots,\delta_{n-1}) \] there is a unique value \(\varphi(z_1,\cdots,z_{n-1})\in \t(w_n;\delta_n)\) such that \[ f\big(z_1,\cdots,z_{n-1},\varphi(z_1,\cdots,z_{n-1})\big)=0\,, \] and necessarily \(\varphi(w_1,\cdots,w_{n-1})=w_n\); we need merely show that this function \(\varphi\) is holomorphic. However, it follows from a familier result in one complex variable that \[ \varphi(z_1,\cdots,z_{n-1})=\frac{1}{2\pi i}\int_{|\zeta_n-w_n|=\delta_n} \zeta_n\frac{\partial f(z_1,\cdots,z_{n-1},\zeta_n)/\partial \zeta_n}{f(z_1,\cdots,z_{n-1},\zeta_n)}\operatorname{d}\!\zeta_n\,. \tag{3}\] By Lemma 2 the function \(f(z_1,\cdots,z_{n-1},\zeta_n)\) is never zero when \[ (z_1,\cdots,z_{n-1}) \in \t(w;\delta_1,\cdots,\delta_{n-1}) \] and \(|\zeta_n-w_n|=\delta_n\); consequently the integrand Equation 3 is a holomorphic function of \((z_1,\cdots,z_{n-1})\) in \(\delta(w;\delta_1,\cdots,\delta_{n-1})\), so the function \(\varphi\) is also holomorphic as desired.
