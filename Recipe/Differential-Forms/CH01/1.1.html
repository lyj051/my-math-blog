Differential forms in \(\mathbb{R}^3\)

Warning

Here by differentiable functions we mean smooth functions in the most textbooks.

It’s quite important for beginners to make the convention: \((dx_i)_p \in (\mathbb{R}^n_p)^*\) denotes the differential of the coordinate function \(x_i\) at the point \(p \in \mathbb{R}^n\) which is a linear mapping;

\(dx_i\) denotes the differential form of degree 1, as we shall define below.

\[ \begin{aligned} dx_i:\mathbb{R}^n&\rightarrow\bigsqcup_{p\in \mathbb{R}^n} (\mathbb{R}^n_p)^*\\ p &\mapsto (dx_i)_p \end{aligned} \]

Notations

  • \(\mathbb{R}^{3}\) is defined to be the set of all real triples; the element of it is called point.

  • Let \(p\) be a point of \(\mathbb{R}^3\); The set of vectors which have origin at \(p\), i.e., \(\{q-p: q \in \mathbb{R}^3\}\), is called the tangent space of \(\mathbb{R}^3\) at \(p\) and will be denoted by \(\mathbb{R}_{p}^3\); Clearly it has the structure of \(\mathbb{R}\)-vector-sapce of which the canonical basis is denoted by \(\{e_1,e_2,e_3\}\) (with subtle abuse of notations, we will drop the subscript \(p\)).

  • A vector field in \(\mathbb{R}^3\) is a map \[ v:\mathbb{R}^3 \rightarrow \bigsqcup_{p \in \mathbb{R}^3}{\mathbb{R}_{p}^3} \] which associates to each point \(p\) a vector \(v(p)\in \mathbb{R}_{p}^3\); Thus we can write \(v\) as \[ v(p)=a_1(p)e_1+a_2(p)e_2+a_3(p)e_3 \] thereby defining three functions \(a_i:\mathbb{R}^3 \to \mathbb{R}\) that characterize the vector field \(v\).

    We say that a vector field \(v\) is differentiable if the functions \(a_i\) which define it are differentiable.

  • To each tangent space \(\mathbb{R}_{p}^3\) we can associate its dual space \((\mathbb{R}_p^3)^{*}\); i.e. the set of all linear maps (also called linear forms) \(\varphi: \mathbb{R}_{p}^3 \to \mathbb{R}\).

    The canonical dual basis of \((\mathbb{R}_p^3)^{*}\) is denoted by \(\{(dx_1)_p,(dx_2)_p,(dx_3)_p\}\); by definition of dual basis we have: \[ (dx_i)_p(e_j)=1 \text{ if } i=j; \ =0 \text{ if } i\neq j \]

Indeed, \((dx_i)_p\)’s as dual basis defined above are the differentials of the coordinate functions \(x_i\)’s at the point \(p\).

  • clearly, \((df)_p \in (\mathbb{R}_p^3)^{*}\) for any \(f\) differentiable at \(p\).
Definition 1: A field of linear forms

A field of linear forms (also called exterior form of degree 1) in \(\mathbb{R}^3\) is a map \(\omega\) that associates to each point \(p\in \mathbb{R}^3\) an element \(\omega(p) \in (\mathbb{R}_p^3)^{*}\); \(\omega\) can be written as: \[ \omega(p)=a_1(p)(dx_1)_p+a_2(p)(dx_2)_p+a_3(p)(dx_3)_p \] thus we may write \[ \omega=\sum_{i=1}^{3}a_idx_i \] where \(a_i\) are real functions in \(\mathbb{R}^3\).

If the functions \(a_i\) are differentiable, \(\omega\) is called a differential form of degree \(1\).

As the convention we made at first, \(dx_i\) is the differential form of degree form of degree \(1\) which associates to each point \(p\) the differential of the \(i\)-th coordinate function; i.e. \((dx_i)_p\)

Note that field of linear forms and vector field are the same except for the codomain.

Notations

  • \(\wedge^{2}(\mathbb{R}^{3}_{p})^*\)

    \(\wedge^{2}(\mathbb{R}^{3}_{p})^*\) is defined to be the set of maps \(\varphi: \mathbb{R}^3_p \times \mathbb{R}^3_p \rightarrow \mathbb{R}\) that are bilinear and alternate;i.e. \(\varphi(x_1,x_2)=-\varphi(x_2,x_1)\).

    With the usual opeartions of functions the set \(\wedge^{2}(\mathbb{R}^{3}_{p})^*\) becomes a vector space naturally.

  • Conversely, when two functions \(\varphi_1,\varphi_2 \in (\mathbb{R}^3_p)\) are given, we can obtain an element \(\varphi_1 \wedge \varphi_2 \in \wedge^{2}(\mathbb{R}^{3}_{p})^*\) by setting: \[ (\varphi_1 \wedge \varphi_2)(v_1,v_2)=\operatorname{det}(\varphi_i({v_j})) \]

  • The element \((dx_1)_p \wedge (dx_2)_p \in \wedge^{2}(\mathbb{R}^3_{p})^*\) will be denoted by \((dx_1 \wedge dx_2)_p\). It is easy to see that the set \(\{(dx_i \wedge dx_j)_p: 1 \leq i < j \leq 3\}\) is a basis for \(\wedge^2(\mathbb{R}^3_p)^*\); Furthermore we have \[ (dx_i \wedge dx_j)_p=-(dx_i \wedge dx_j)_p, \ i \neq j; \ (dx_i \wedge dx_i)_p=0 \]

  • Geometric Interpretation \[\ (\omega_ \wedge \nu )(V_1,V_2)=\pm \operatorname{area}[(\omega(V_1),\nu(V_1)),(\omega(V_2),\nu(V_2))] \] where \(\omega,\nu \in (\mathbb{R}^3_p)^*\)

Definition 2: Field of bilinear alternating forms

A field of bilinear alternating forms or exterior form of degree of 2 in \(\mathbb{R}^3\) is a map \(\omega\) that associates to each \(p \in \mathbb{R}^3\) an element \(\omega(p) \in \wedge^{2}(\mathbb{R}^{3}_{p})^*\); thus \(\omega\) admits the form: \[ \omega(p)=a_{12}(p)(dx_1 \wedge dx_2)_p + a_{13}(p)(dx_1 \wedge dx_3)_p +a_{23}(p)(dx_2 \wedge dx_3)_p \] or \[ \omega=\sum_{i <j }a_{ij}dx_i \wedge dx_j \qquad i,j=1,2,3 \] where \(a_{ij}\) are real functions in \(\mathbb{R}^3\). When the functions \(a_{ij}\) are differentiable, \(\omega\) is said to be a differential form of degree 2.

Differential forms in \(\mathbb{R}^n\)

Let \(\wedge^k(\mathbb{R}^n_p)^*\) be the set of all \(k\)-linear alternating maps: \[ \varphi: \mathbb{R}^n_p \times \dots \times \mathbb{R}^n_p \rightarrow \mathbb{R}^n_p \]

Given \(\varphi_1, \dots, \varphi_k \in (\mathbb{R}^n_p)^*\), we can obtain an element \(\varphi_1\wedge \dots\wedge \varphi_k \in \wedge^k(\mathbb{R}^n_p)^*\) by setting \[ (\varphi_1\wedge \dots\wedge \varphi_k) (v_1,\dots,v_k)=\operatorname{det}(\varphi_i(v_j)) \] In particular, \((dx_{i_1})_p\wedge\dots\wedge(dx_{i_k})_p \in \wedge^k(\mathbb{R}^n_p)^*\) where \(i_j \in \{1,2, \dots,n\}\). We will denote this element by \((dx_{i_1}\wedge\dots\wedge dx_{i_k})_p\).

Proposition 1

The set \[ (dx_{i_1}\wedge\dots\wedge dx_{i_k})_p \qquad 1\leq i_1 < \dots < i_k \leq n \] is a basis for the vector space \(\wedge^k(\mathbb{R}^n_p)^*\).

Proof.

  • The elements of the set are linearly independent.

    Suppose that \[ \sum_{i_1 <\dots<i_k}a_{i_1\dots i_k}(dx_{i_1}\wedge\dots\wedge dx_{i_k})_p=0 \] Then \[ (\sum_{i_1 <\dots<i_k}a_{i_1\dots i_k}(dx_{i_1}\wedge\dots\wedge dx_{i_k})_p)(e_{j_1},\dots,e_{j_k})=a_{j_1\dots j_k}=0 \] where \(j_1<\dots<j_k\) and \(j_l \in \{1,\dots,n\}\).

  • If \(f\in \wedge^k(\mathbb{R}^n_p)^*\), \(f\) is a linear combination of the form: \[ f=\sum_{i_1 <\dots<i_k}a_{i_1\dots i_k}(dx_{i_1}\wedge\dots\wedge dx_{i_k})_p \] For this, set \(g\in\wedge^k(\mathbb{R}^n_p)^*\): \[ g=\sum_{i_1 <\dots<i_k}f(e_{i_1},\dots,e_{i_k})(dx_{i_1}\wedge\dots\wedge dx_{i_k})_p \] Then we have \(g(e_{i_1},\dots,e_{i_k})=f(e_{i_1},\dots,e_{i_k})\) for any \((e_i)\);thus \(f=g \in \wedge^k(\mathbb{R}^n_p)^*\).

Definition 3: Exterior \(k\)-form

An exterior \(k\)-form in \(\mathbb{R}^n\) is a map \(\omega\) that associates to each \(p\in \mathbb{R}^n\) an element \(\omega(p)\) in \(\wedge^k(\mathbb{R}^n_p)^*\); by proposition 1, \(\omega\) can be written as \[ \omega(p)=\sum_{i_1 <\dots<i_k}a_{i_1\dots i_k}(p)(dx_{i_1}\wedge\dots\wedge dx_{i_k})_p \] or (for notational convenience) \[ \omega=\sum_{I}a_{I}dx_{I} \] where index set \(I\) runs over all sets of the form \(\{i_1<\dots<i_k:i_j\in \{1,\dots,n\}\}\) and each \(a_I\) is a real functon in \(\mathbb{R}^n\). When the \(a_I\)’s are differentiable, \(\omega\) is said to be a differential \(k\)-form.

We also set the convention that a differential \(0\)-form is a differentiable function \(f:\mathbb{R}^n \to \mathbb{R}\).

From now on, we will restrict ourselves to differential forms and we will call them \(k\)-forms for convenience.

We are going to define some operations on \(k\)-forms in \(\mathbb{R}^n\).

  1. If \(\omega\) and \(\varphi\) are two \(k\)-forms: \[ \omega=\sum_Ia_Idx_I, \qquad \varphi=\sum_Ib_Idx_I \] we can define their sum \[ \omega+\varphi=\sum_I(a_I+b_I)dx_I \]

  2. If \(\omega\) is a \(k\)-form and \(\varphi\) is an \(s\)-form, we can define their exterior product \(\omega \wedge\varphi\), which is an \((s+k)\)-form, as follows:

Definition 4: Exterior product of two forms

Let \[ \begin{aligned} &\omega=\sum_{I}a_Idx_I, \qquad I=(i_1,\dots,i_k), \qquad 1\leq i_1<\dots<i_k\leq n \\ & \varphi=\sum_{I}a_Jdx_J, \qquad J=(j_1,\dots,j_s), \qquad 1\leq j_1<\dots<j_s\leq n \end{aligned} \] By definition, \[ \omega \wedge \varphi:=\sum_{IJ}a_Ib_Jdx_I\wedge dx_J \]

Proposition 2

Let \(\omega\) be a \(k\)-form, \(\varphi\) be an \(s\)-form and \(\theta\) be an \(r\)-form. Then: \[ \begin{aligned} &(a):\ (\omega \wedge \varphi)\wedge \theta=\omega \wedge (\varphi \wedge \theta) \\ &(b):\ (\omega \wedge \varphi)=(-1)^{ks}(\varphi \wedge \omega) \\ &(c):\ \omega \wedge (\varphi+\theta)=\omega\wedge\varphi+\omega\wedge\theta, \quad \text{if } r=s \end{aligned} \]

Warning

Although \(dx_i \wedge dx_i =0\), it is not true that for any form \(\omega \wedge \omega=0\). For instance, if \[ \omega=x_1dx_1\wedge dx_2+x_2dx_3\wedge dx_4, \] then \[ \omega\wedge\omega=2x_1x_2dx_1\wedge dx_2\wedge dx_3 \wedge dx_4 \]

Substitution of Variables

One of the most important features of differential forms is the way they behave under differentiable maps.

Definition 5

Let \(f: \mathbb{R}^n \rightarrow \mathbb{R}^m\) be a differentiable map. Then \(f\) induces a map \(f^*\) that takes \(k\)-forms in \(\mathbb{R}^m\) into \(k\)-forms in \(\mathbb{R}^n\) and is defined as follow;let \(\omega\) be a \(k\)-form in \(\mathbb{R}^m\). By definition, \(f^*(\omega)\) is the \(k\)-form in \(\mathbb{R}^n\) given by \[ (f^*\omega)(p)(v_1,\dots,v_k)=\omega(f(p))(df_p(v_1),\dots,df_p(v_k)) \] Here \(p \in \mathbb{R}^n\), \(v_1,\dots,v_k\in \mathbb{R}^n_p\), and \(df_p: \mathbb{R}^n_p \rightarrow \mathbb{R}^m_{f(p)}\) is the differential of the map \(f\) at \(p\)

We set the convention that if \(g\) is a \(0\)-form, \[ f^*(g)=g\circ f \]

Proposition 3

Let \(f:\mathbb{R}^n \rightarrow \mathbb{R}^m\) be a differentiable map, \(\omega\) and \(\varphi\) be \(k\)-forms on \(\mathbb{R}^m\) and \(g:\mathbb{R}^m\rightarrow \mathbb{R}\) be a \(0\)-form on \(\mathbb{R}^m\). Then: 1. \(f^*(\omega+\varphi)=f^*\omega+f^*\varphi\) 2. \(f^*(g\omega)=f^*(g)f^*(\omega)\) 3. If \(\varphi_1,\dots,\varphi_k\) are \(1\)-forms in \(\mathbb{R}^m\), \(f^*(\varphi_1\wedge\dots\wedge\varphi_k)=f^*(\varphi_1)\wedge\dots\wedge f^*(\varphi_k)\).

Proof.

  1. \[ \begin{equation} \begin{split} f^*(\omega+\varphi)(p)(-)&=(\omega+\varphi)(f(p))(df_p(-)) \\ &=\omega(f(p))(df_p(-))+\varphi(f(p))(df_p(-)) \\ &=f^*(\omega)(p)(-)+f^*(\varphi)(p)(-) \end{split} \end{equation} \]

  2. \[ \begin{equation} \begin{split} f^*(g\omega)(p)(-)&=(g\omega)(f(p))(df_p(-)) \\ &=g(f(p)) \cdot \omega(f(p))(df_p(-)) \\ &=f^*(g)f^*(\omega) \end{split} \end{equation} \]

  3. \[ \begin{equation} \begin{split} f^*(\varphi_1\wedge\varphi_2)(p)(v_1,v_2)&=(\varphi_1\wedge\varphi_2)(f(p))(df_p(v_1),df_p(v_2)) \\ &=\operatorname{det}(\varphi_i(df_p(v_j))) \\ &=\operatorname{det}(f^*(\varphi_i)(p)(v_j)) \\ &=(f^*(\varphi_1)\wedge f^*(\varphi_2))(p) \end{split} \end{equation} \]

We can now present the promised interpretation of \(f^*\). Let \((x_1,\dots,x_n)\) br coordinates in \(\mathbb{R}^n\), \((y_1,\dots,y_m)\) be coordinates in \(\mathbb{R}^m\) and let \(f:\mathbb{R}^n \rightarrow \mathbb{R}^m\) be written as \[ y_1=f_1(x_1,\dots,x_n),\dots,y_m=f_m(x_1,\dots,x_n) \quad \tag{$\star$} \] Let \(\omega=\sum_{I}a_Idy_I\) be a \(k\)-form in \(\mathbb{R}^m\). By using the above properties of \(f^*\), we obtain: \[ f^*\omega=\sum_{I}f^*(a_I)(f^*dy_{i_1})\wedge\dots\wedge(f^*dy_{i_k}) \] Since \[ f^*(dy_i)(p)(v)=(dy_i)_{(f(p))}((df)_p(v))=((dy_i)_{(f(p))} \circ (df)_p)(v)=(d(y_i \circ f))_p(v)=({df_{i}})_{p}(v), \] we have \[ f^*\omega=\sum_Ia_I(f_{1}(x_1,\dots,x_n),\dots,f_m(x_1,\dots,x_n))df_{i_1}\wedge\dots\wedge f_{i_k} \] Thus to apply \(f^*\) to \(\omega\) is equivalent to ‘substitute’ in \(\omega\) the variables \(y_i\) and their differentials by the functions of \(x_k\) and \(dx_k\) obtained from \(\star\).

Remark 1

In various situations, it is convenient to use differential forms defined only on some open set \(U\subset \mathbb{R}^n\) and not on the entire \(\mathbb{R}^n\).

It is clear that everything done so far extends trivially to this situation.

Example 6: Polar coordinates

Let \(\omega\) be the \(1\)-form in \(\mathbb{R}^2-\{(0,0)\}\) by \[ \omega=-\frac{y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy \] Let \(U\) be the set in the plane \((r,\theta)\) given by \[ U=\{r>0;0<\theta<2\pi\} \] And let \(f:U \rightarrow \mathbb{R}^2\) be the map: \[ f(r,\theta)= \begin{cases} x=r\cos \theta \\ y=r\sin \theta \end{cases} \] Let us compute \(f^*\omega\). Since \[ \begin{aligned} &dx=d(r\cos \theta)=\cos\theta dr-r\sin \theta d\theta \\ &dy=d(r \sin \theta)=\sin \theta dr+r\cos \theta d\theta \end{aligned} \] Doing substitution and we obtain \[ \begin{equation} \begin{split} &f^*(-\frac{y}{x^2+y^2}dx+\frac{x}{x^2+y^2}dy) \\ =&-\frac{r\sin \theta}{r^2}(\cos \theta dr-r\sin\theta d\theta)+\frac{r\cos\theta}{r^2}(\sin\theta dr+r\cos \theta d\theta)\\ =&d\theta \end{split} \end{equation} \]

Notice that the addition of differential forms commutes with the substitution of variables; We will now show that the same holds for the exterior product.

Proposition 4

Let \(f:\mathbb{R}^n\rightarrow\mathbb{R}^m\) be a differentiable map. Then - \(f^*(\omega \wedge \varphi)=(f^*\omega)\wedge(f^*\varphi)\), where \(\omega\) and \(\varphi\) any two forms in \(\mathbb{R}^m\). - \((f\circ g)^*\omega=g^*(f^*\omega)\), where \(g:\mathbb{R}^p \rightarrow \mathbb{R}^n\) is a differentiable map.

Proof. The proof are straightforward.

Exterior Differential

We are now going to define an operation on differential form that generalizes the differentiation of functions. Let \(g:\mathbb{R}^n \rightarrow \mathbb{R}\) be a \(0\)-form (i.e. a differentiable function). Then the differential: \[ dg=\sum_{i=1}^n\frac{\partial g}{\partial x_i}dx_i \] is a \(1\)-form. We want to generalize this process by defining an operation that takes \(k\)-forms into \((k+1)\)-forms.

Definition 7

Let \(\omega=\sum_{I}a_Idx_I\) be a \(k\)-form in \(\mathbb{R}^n\). The exterior differential \(d\omega\) of \(\omega\) is defined by \[ d\omega=\sum_Ida_I\wedge dx_I \]

Example 8

Let \(\omega=xyzdx+yzdy+(x+z)dz\) and let us compute \(d\omega\): \[ \begin{aligned} d\omega&=d(xyz)\wedge dx+d(yz) \wedge dy +d(x+z)\wedge dz \\ &=(yzdx+xzdy+xydz)\wedge dx+(ydz+zdy)\wedge dy+(dx+dz)\wedge dz \\ &=-xzdx\wedge dy+(1-xy)dx\wedge dz-ydy\wedge dz \end{aligned} \]

We now present some properties of exterior differentiation. (3) is probably the most important one and (4) means that the operation \(d\) commmutes with substitution of variables.

Proposition 5
  1. \(d(\omega_1+\omega_2)=d\omega_1+d\omega_2\), where \(\omega_1,\omega_2\) are \(k\)-forms
  2. \(d(\omega\wedge\varphi)=d\omega\wedge\varphi+(-1)^k\omega\wedge d\varphi\), where \(\omega\) is a \(k\)-form and \(\varphi\) is an \(s\)-form
  3. \(d(d\omega)=d^2\omega=0\)
  4. \(d(f^*\omega)=f^*(d\omega)\), where \(\omega\) is a \(k\)-form in \(\mathbb{R}^m\) and \(f:\mathbb{R}^n \rightarrow \mathbb{R}^m\) is a differentiable map.

Proof.

  1. Let \(\omega=\sum_Ia_Idx_I\) and \(\varphi=\sum_Jb_Jdx_J\); then \(\omega \wedge \varphi=\sum_{IJ}a_Ib_Jdx_I\wedge dx_J\); thus \[ \begin{aligned} d(\sum_{IJ}a_Ib_Jdx_I\wedge dx_J)&=\sum_{IJ}d(a_Ib_J)\wedge dx_I \wedge dx_J \\ &=\sum_{IJ}a_Idb_J\wedge dx_I \wedge dx_J +\sum_{IJ}b_Jda_I\wedge dx_I\wedge dx_J \\ &=(-1)^k\omega\wedge d\varphi+d\omega\wedge\varphi \end{aligned} \]

  2. Let us first assume that \(\omega\) is a \(0\)-form, i.e., \(\omega\) is a function \(f:\mathbb{R}^n\to\mathbb{R}\) that associates to each \((x_1,\ldots,x_n)\in\mathbb{R}^n\) the value \(f(x_1,\ldots,x_n)\). Then

\[ \begin{aligned} d(df) &=d\left(\sum_{j=1}^n\frac{\partial f}{\partial x_j}\,dx_j\right)\\ &=\sum_{j=1}^n d\left(\frac{\partial f}{\partial x_j}\right)\wedge dx_j\\ &=\sum_{j=1}^n\left(\sum_{i=1}^n \frac{\partial^2f}{\partial x_i\partial x_j}\,dx_i\right)\wedge dx_j. \end{aligned} \]

Since

\[ \frac{\partial^2f}{\partial x_i\partial x_j} = \frac{\partial^2f}{\partial x_j\partial x_i} \]

and

\[ dx_i\wedge dx_j=-dx_j\wedge dx_i,\qquad i\neq j, \]

we obtain that

\[ d(df) = \sum_{i<j} \left( \frac{\partial^2f}{\partial x_i\partial x_j} - \frac{\partial^2f}{\partial x_j\partial x_i} \right) dx_i\wedge dx_j =0. \]

Now let

\[ \omega=\sum_i a_i\,dx_i. \]

By 1, we can restrict ourselves to the case \(\omega=a_1dx_1\) with \(a_1\neq0\). By 2, we have that

\[ d\omega = da_1\wedge dx_1+a_1d(dx_1). \]

But

\[ d(dx_1)=d(1)\wedge dx_1=0. \]

Therefore,

\[ \begin{aligned} d(d\omega) &=d(da_1\wedge dx_1)\\ &=d(da_1)\wedge dx_1+da_1\wedge d(dx_1)\\ &=0, \end{aligned} \]

since \(d(da_1)=0\) and \(d(dx_1)=0\), which proves 3.

  1. We will first prove the result for a \(0\)-form. Let \(g:\mathbb{R}^m\to\mathbb{R}\) be a differentiable function that associates to each \((y_1,\ldots,y_m)\) the value \(g(y_1,\ldots,y_m)\). Then

\[ \begin{aligned} f^*(dg) &=f^*\left(\sum_i\frac{\partial g}{\partial y_i}\,dy_i\right)\\ &=\sum_{ij}\frac{\partial g}{\partial y_i} \frac{\partial f_i}{\partial x_j}\,dx_j\\ &=\sum_j\frac{\partial(g\circ f)}{\partial x_j}\,dx_j\\ &=d(g\circ f) =d(f^*g). \end{aligned} \]

Now, let

\[ \varphi=\sum_i a_i\,dx_I \]

be a \(k\)-form. By using the above, and the fact that \(f^*\) commutes with the exterior product, we obtain

\[ \begin{aligned} d(f^*\varphi) &=d\left(\sum_i f^*(a_i)f^*(dx_I)\right)\\ &=\sum_i d(f^*(a_i))\wedge f^*(dx_I)\\ &=\sum_i f^*(da_i)\wedge f^*(dx_I)\\ &=f^*\left(\sum_i da_i\wedge dx_I\right)\\ &=f^*(d\varphi), \end{aligned} \]

which proves 4.
