We shall introduce two important and basic examples of varieties: \(\mathbb{A}^{n}\) and \(\mathbb{P}^{n}\).

NoteDefinition

\(\mathbb{A}^n\) is defined as \(\Spec (k[X_1, \dots, X_n])\) where \(k\) is an algebraically closed field.

Set-theoretically, \(\mathbb{A}^n=\{(x_1, \dots, x_n): x_i \in k, 1 \leq i \leq n\}\) since every \(k\)-algebra homomorphism is determined by the images \(x_{i}\) of \(X_{i}\) which can be arbitrary in \(k\). As a variety \(\mathbb{A}^n\) is called an affine \(n\)-space.

Furthermore if X is a space with functions and \(f:X \to \mathbb{A}^n\) is a mapping given by \(f(x)=(f_1(x),\dots,f_{n}(x))\) then \(f\) is a morphism if and only if each \(f_i\) is regular function on X.

Tip 1: Proof
  • We will use the already proven lemma:

If \(X\) is a space with functions then \(X \xrightarrow{f}\mathbb{A}^{1}\) is a morphism if and only if it’s a regular function on \(X\).

  • \(\mathbb{A}^{n} \xrightarrow{p_{i}}\mathbb{A}^{1}\) is a morphism as \(p_i=X_i \in k[X_1,\dots,X_n]\). If \(f\) is a morphism from \(X\) to \(\mathbb{A}^n\), then \(f_i=p_{i} \circ f\) is a morphism.

  • Conversely suppose that \(f_{i}\) is morphism for each \(i\). First we show that \(f\) is continuous. Let \(V(P)\) be a closed set of \(\mathbb{A}^n\). We have \[ f^{-1}(V(P))=\{x \in X: p(f_1(x),\dots, f_n(x))=0, \forall p \in P\} \] Since \(f_i\) is regular on \(X\) and \(p(f_1(x),\dots, f_n(x))\) is a function obtained by algebraic operations without division in \(\mathcal{O}(X)\), \(p \circ f\) is a regular funciton on \(X\). Hence \(X-D(p \circ f)\) is a closed subset and so is \(f^{-1}(V(p))= \bigcap_{p\in P} {(X-D(p \circ f))}\). As expected \(f\) is continuous.

  • Next We show that \(f^*(g)=g\circ f\) is a regular function on \(f^{-1}(U)\) where \(g \in \mathcal{O}_{\mathbb{A}^n}(U)\). Wlog we assume that \(U=D(h)\), then \(g\) admits a form \(\frac{a(x_1,\dots,x_n)}{h(x_1,\dots,x_n)}\) on \(U\). Then \(g \circ f\) admits a form \(\frac{a(f_1(x),\dots,f_n(x))}{h(f_1(x),\dots,f_n(x))}\) on \(f^{-1}(U)\). Since \(f_{i}:X \rightarrow \mathbb{A}^1\) is a morphism, it is indeed a regular function on \(X\). Therefore functions which admit the form \(a(f_1(x),\dots,f_n(x))\) are regular on \(X\). Moreover since \(D(h(f_1(x),\dots,f_n(x)))=f^{-1}(U)\), \(1/h(f_1(x),\dots,f_n(x))\) is regular on \(f^{-1}(U)\). Hence \(\frac{a(f_1(x),\dots,f_n(x))}{h(f_1(x),\dots,f_n(x))}\) is regular on \(f^{-1}(U)\) as expected.

Another fact is that any affine variety \(X\) is isomorphic (non-canonically) to a closed subvariety of \(\mathbb{A}^{n}\) corresponding to a surjection \(k[X_1,\dots,X_n]\rightarrow A\) where \(A=\mathcal{O}(X)\). A subvariety of \(\mathbb{A}^n\) (or any other affine variety) is called quasi-affine.

For instance the punctured affine space \(\mathbb{A}^{n}-\{0\}\).

Note 1: Lemma

  1. \(\mathcal{O}(\mathbb{A}^1-\{0\})=k[X_1,X_1^{-1}]\)

  2. If \(n>1\), \(\mathcal{O}(\mathbb{A}^n-\{0\})=k[X_1,\dots,X_n]\)

TipProof

If \(n=1\), \(\mathbb{A}^{1}-\{0\}\) is the open subvariety \(D(X)\) of \(\mathbb{A}^1\). So \(\mathbb{A}_1-\{0\} \cong \Spec (k[X]_{(X)})\) as spaces with functions. Hence \(\mathcal{O}(\mathbb{A}^1-\{0\})=\mathcal{O}(\Spec (k[X]_{(X)}))=k[X]_{(X)}=k[X,X^{-1}]\)

If \(n>1\), \(\mathbb{A}^n-\{0\}=\bigcup_{i=1}^{n}{D(X_i)}\) and \[ \mathcal{O}(D(X_i))=k[X_1,\dots,X_n,X_i^{-1}] \] Thus we have

\(\mathcal{O}(\mathbb{A}^n-\{0\})=\bigcap_{i}{k[X_1,\dots,X_n,X_i^{-1}]}=k[X_1,\dots,X_n]\) .

CautionExericse

Prove that the quasi-affine variety \(\mathbb{A}^2-\{0\}\) is not affine.

TipProof
  • There is a natural isomorphism \(\operatorname{id}(X_i)=X_i\) in \(\operatorname{Hom}_{k}(\mathcal{O}(\mathbb{A}^2),\mathcal{O}(\mathbb{A}^2-\{0\}))\). \[ \mathcal{O}(\mathbb{A}^2) \xrightarrow{\operatorname{id}} \mathcal{O}(\mathbb{A}^2-\{0\}) \] Since \(\mathbb{A}^2\) is affine, there is a unique morphism \(f\) in \(\operatorname{Mor}(\mathbb{A}^2-\{0\},\mathbb{A}^2)\) such that \(f^*=\operatorname{id}\) i.e. \[ \mathbb{A}^2-\{0\} \xrightarrow{f} \mathbb{A}^2 \xrightarrow{X_i} k \] in which \(f^*(X_i)=\operatorname{id}(X_i)=X_i=X_i \circ f\) and we thus have \(X_i(P)=(X_i \circ f)(P)\) which means that \(f\) must be the natural inclusion map.
  • But we know if \(\mathbb{A}^2-\{0\}\) is affine then there is a morphism \(g\) in \(\operatorname{Mor}(\mathbb{A}^2,\mathbb{A}^2-\{0\})\) such that \(g^*=\operatorname{id}\) as above.
  • Consider \(g \circ f\in \operatorname{Mor}(\mathbb{A}^2-\{0\},\mathbb{A}^2-\{0\})\). It follows that \((g \circ f)^*=\operatorname{id}=(\operatorname{id}_{\mathbb{A}^2-\{0\}})^*\). If \(\mathbb{A}^2-\{0\}\) is affine, we have \(g \circ f \equiv \operatorname{id}_{\mathbb{A}^2-\{0\}}\).
  • Similarily we have \(f \circ g \equiv \operatorname{id}_{\mathbb{A}^2}\). Therefore \(f\) is an isomorphism and thus must be surjective. This is a contradiction!

Set-theoretically \(\mathbb{P}^n\) is the quotient set \[ (\mathbb{A}^{n+1}-\{0\})/k^{\times}=\{(x_0,x_1,\dots,x_n)\neq 0: x_i \in k\} / \sim \text{ where } (x_0,\dots,x_n) \sim \lambda(x_0,\dots,x_n) \text{ for any } \lambda \in k-\{0\} \] We want to define it as a quotient space with functions. Let \(\pi:\mathbb{A}^{n+1}-\{0\} \to \mathbb{P}^{n}\) send a vector to all vectors with the same direction. A subset \(U\) of \(\mathbb{P}^n\) is open if and only if \(\pi^{-1}(U)\) is open. A function \(f\) on \(U\) is regular if and only if \(\pi^*(f)\) is regular on \(\pi^{-1}(U)\). We claim that with this definition of a space with functions \(\mathbb{P}^n\) is a variety. Let \(0\leq i \leq n\). Let \(E_i=\{(x_0,\dots,x_n)\in \mathbb{P}^n:x_i \neq 0\}\).

ImportantClaim

The \(E_i\) form an open covering of \(\mathbb{P}^n\) by open affine subvarieties. In fact, \(E_i=\Spec (k[X_0/X_i,\dots,X_i/X_i,\dots,X_n/X_i])\).

Proof:

It suffices to show the second fact. Let \(D_i=D(X_i)\) in \(\mathbb{A}^{n+1}\). Then \(\pi^{-1}E_i=D_i\). So \(E_i\) is open. And we have the following: \[ \mathcal{O}_{\mathbb{P}^n}(E_i)=\{f:\pi^*f \in \mathcal{O}(\pi^{-1}(E_i))\}=\{f:f \circ \pi \in k[X_0,\dots,X_n,1/X_i]\} \simeq \{f\in k[X_0,\dots,X_n,1/X_i] \text{ such that }f(\lambda x)=f(x) \text{ for all } \lambda \neq 0\} \]

TipScrutiny

As \((f \circ \pi )(\lambda x)=(f \circ \pi )(x)\) we have $f f $, denoted by \(\varphi\). Define \(\varphi^{-1}\): \(f \mapsto f^\prime\) where \(f^{\prime}\) is defined as below: \[ \begin{aligned} f^\prime: E_i & \rightarrow k \\ [v_1] & \mapsto f(v_1) \end{aligned} \] We shall check that \(f^\prime\) is well-defined: Suppose that \([v_1]=[v_2]\) then \(v_1=\lambda v_2\) for some \(\lambda\neq 0\), thus \(f^{\prime}(v_1)=f(v_1)=f(\lambda v_2)=f(v_2)=f^{\prime}(v_2)\).

\[ \begin{aligned} &(\varphi \circ \varphi^{-1})(f)=\varphi(f^{\prime})=f^{\prime} \circ \pi \equiv f \\ &(\varphi^{-1} \circ \varphi)(f)=\varphi^{-1}(f \circ \pi)=([v] \mapsto (f \circ \pi)(v)) \equiv f \\ & \varphi(f_1+(\times)f_2)=(f_1+(\times)f_2) \circ \pi=f_1 \circ \pi +(\times)f_2\circ \pi=\varphi(f_1)+(\times)\varphi(f_2) \\ &\varphi^{-1}(f_1+(\times)f_2)=([v]\mapsto (f_1+(\times)f_2)(v))=([v]\mapsto f_1(v))+(\times)([v]\mapsto f_2(v))=\varphi^{-1}(f_1)+(\times)\varphi^{-1}(f_2) \end{aligned} \]

If \(f \in k[X_0,\dots,X_n,1/X_i]\), \(f\) admits the form (c.f.): \[ f=f_{d_1}+\dots+f_{d_m}, f_{d_i} \text{ is the homogeneous component} \] As \(f(\lambda x)=f(x), \forall \lambda\neq0\), we have

\[ \begin{aligned} &\lambda^{d_1}f_{d_1}+\dots+\lambda^{d_m}f_{d_m}=f_{d_1}+\dots+f_{d_m} \\ & \Rightarrow\sum_{i=1}^{m}(\lambda^{d_i}-1)f_{d_i}=0 \end{aligned} \]

Since \(k\) is infinite, \(f_{d_i}\) must be zero if \(d_i \neq 0\); thus \(f\) is a homogeneous element of degree \(0\) and belongs to \(k[X_0/X_i, \dots,X_i/X_i,\dots,X_n/X_i]\). Denote it by \(B\); Thus we have \(\mathcal{O}_{\mathbb{P}^n}(E_i)\cong B\) as f.g.\(k\)-algebras with no nilpotents. Thus we have \(E_i \cong \Spec (k[X_0/X_i, \dots,X_i/X_i,\dots,X_n/X_i])\) as affine varieties.

\(\mathbb{P}^n\) is called projective n-space.

A closed subvariety of a projective space is called projective. An arbitrary subvariety of a projective space is called quasi-projective. We may compute the global regular fucntions on \(\mathbb{P}^n\): they are just constants.

NoteLemma

\(\mathbb{P}^n=k\).

Proof. If \(n=0\), \(\mathbb{P}^0\) is just a point and the result is clear; Assume that \(n \geq 1\), then \(\pi^{*}\) is injective, for \[ \mathbb{A}^{n+1}-\{0\} \xrightarrow{\pi} \mathbb{P}^{n} \xrightarrow{f}k \] if \(f \circ\pi =0\) then \(f \equiv 0\) since \(\pi\) is surjective.

Since \(\pi^*:\mathcal{O}(\mathbb{P}^{n}) \rightarrow \mathcal{O}(\mathbb{A}^{n+1}-\{0\})\) and by lemma, \[ \mathcal{O}(\mathbb{A}^{n+1}-\{0\})=k[X1,\dots,X_{n+1}] \] \(\mathcal{O}(\mathbb{P}^{n})\) is identified with the homogeneous polynomials of degree zero; i.e. constants.

NoteExercise

Let \(f: \mathbb{P}^n \to X\) be a morphism where \(X\) is a quasi-affine variety. Prove that the image of \(f\) is a single point.

Proof. By the exercise, \(f\) is a morphism if and only if \(\mathbb{P}^n \xrightarrow{\iota \circ f} \mathbb{A}^{n}\) is; Then the component functions (by the lemma) are regular functions which are constant and thus the image is just a single point.

NoteExercise

Let \(X\) be a subset of \(\mathbb{P}^n\). Then \(X\) is closed if and only if it has the form \[ \{(X_0,\dots,X_n) \in \mathbb{P}^{n}:f_i(X_0,\dots,X_n)=0 \text{ for some set of homogeneous polynomials } f_i\} \]

Proof.

  • Assume that \(X\) has the desired form, and \(\operatorname{deg}f_i=d_i \in \mathbb{N}\); On \(E_k \cap X\), \(f_i/X_k^{d_i}\) is regular. Then by condition (b) the subset of zeroes of these \(f_i\) is closed in each \(E_k\) and thus \(X\) is closed.

  • Assume that \(X\) is a closed subset of \(\mathbb{P}^n\); \(X \cap E_k\) is closed in \(E_k \cong \mathbb{A}^n\) which implies that \(X \cap E_k\) has the form: \[ \{(x_0, \dots,x_n):x_k \neq 0;f_{k,r}(\frac{x_0}{x_k},\dots,\frac{\hat{x_k}}{x_k},\dots,\frac{x_n}{x_k})=0\} \] Denote \(X_k^{d_{k,r}}f_{k,r}\) by \(F_{k,r}\) where \(d_{k,r}\) is the highest total degree of \(f_{k,r}\). Since \(X_k\) vanishes nowhere in \(E_k\), \(\operatorname{zeroes}(f_{k,r}) = \operatorname{zeroes}(F_{k,r})\) in \(E_k\). Clearly then we have \(X \subseteq \operatorname{zeroes}(F_{k,r})_{1 \leq k \leq n}\) (because \(X_{t}^{d_{t,r}}f_{t,r}(p)=0\) if \(p \in E_t \cap X\) and also zero when \(p \notin E_t\) for \(X_t(p)=0\)); Suppose that there exists a point \(p \in \mathbb{P}^n\) such that \(F_{k,r}(p)=0\), \(p\) must belongs to some \(E_{t}\); \(p\) is then a zero of \(f_{t,r}\); thus \(p \in X\).
